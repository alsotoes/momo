# JULES.md

All project steering rules, engineering standards, and architectural constraints are defined in **one** primary file:
[`openspec/config.yaml`](openspec/config.yaml) (under the `context` block, "Project Steering Rules").

This file is the single source of truth (Rule 39).
Jules (@google-labs-jules) MUST read and reference `openspec/config.yaml` and [`.jules/instructions.md`](.jules/instructions.md) before planning or proposing code changes.
