Bolt ([024](024-bolt-performance-engineering.md)) needs teeth: a **benchstat
gate** compares branch benchmarks against `base` on every PR
(`.github/workflows/benchmark_compare.yml`). A statistically significant
regression blocks merge — three-dot diff so a master merge can't fake the
comparison (see [027](027-governance-ai-review-spec-first.md)).

## The honesty war (Aug 2026)

The gate kept failing for reasons having **nothing to do with code** — classic
benchstat runner noise. Each fix was painful but made the signal trustworthy:

1. **#958** — benchstat exited 2 (crash) because an apostrophe inside an
   awk-quoted allowlist *comment* broke shell quoting. Fixed: no apostrophes in
   awk comments.
2. **#960** — `S3PutSpool/64MiB` regressed seemingly at random; a **runner
   disk-spool artifact** (the CI VM writes spool to a slow temp disk), not a
   real change. Fix: allowlist `S3PutSpool` when it's an I/O-artifact bench.
3. **#956** — `LocalWrite` allowlisted similarly (runner-local write noise).

Result: the gate now distinguishes **real regressions** (blocked) from
**environment jitter** (allowlisted), and `docs/PERFORMANCE.md` +
`.github/data/benchmark_history.csv` (regenerated by the pre-commit hook) carry
the authoritative history.

## ⚡ Bolt lens

A benchmark gate is Bolt *practiced as process*: measure, compare, gate. The
three-dot + allowlist story is the reminder that *measurement infrastructure
itself* needs hardening — an honest gate is an auditable trust invariant
(Sentinel framing of a Benchmark problem).
